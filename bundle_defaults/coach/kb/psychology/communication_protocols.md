# 团队沟通协议 (Communication Protocols)

> 团队配合的本质是**信息高效传递**, 不是 "多说话"。本文档定义教练如何根据玩家 `comm_style` 给出沟通策略。

---

## 沟通的 4 个分级

**核心原则**: 通信成本递增, 信息密度递减。能用 ping 解决就不打字, 能打字解决就不开麦。

| 等级 | 方式 | 成本 | 信息密度 | 适用情境 |
|---|---|---|---|---|
| L1 | **Ping** (信号) | 低 | 高 (位置+意图) | 90% 局内沟通 |
| L2 | **短打字** (3-5 字) | 中 | 中 | ping 不够时 |
| L3 | **长打字** (完整句) | 高 | 高 | 选人/战术规划 |
| L4 | **开麦** (语音) | 极高 | 极高 | 双排/熟人/重要决策 |

---

## Ping 的语义编码 (ARAM 简化版)

LoL 的 ping 不只是 "看这里", 它有精确语义:

| Ping | 默认语义 | ARAM 推荐用法 |
|---|---|---|
| 👀 危险 (Danger) | "这里危险/敌人来了" | 看到敌方关键技能冷却 / 敌方多人聚集 |
| 🟢 进攻 (On My Way) | "我去这边/支援" | 我要切入 / 我要 flash 进 |
| ❓ 信息缺失 (Missing) | "敌人不见了" | 敌方有人 BR 回家 / 看不到 |
| ✨ 注意 (Alert) | "注意这里" | 资源刷新 (草丛 / 增益) |
| 🔵 后撤 (Retreat) | "后撤/不要打" | 我冷却没好 / 阵容不对位 |

**教练发言模板示例**:
- 给 `comm_style: 跟随型`: "你不用打字, 看队友 ping. 他 👀 你就退, 他 🟢 你就跟."
- 给 `comm_style: 指挥型`: "你 ping 节奏 — 团战前用 ✨ ping 关键技能 cd, 队友会跟"

## 按 comm_style 给的沟通策略

### 指挥型 (commanding)

**优势**: 主动调度, 信息发起者
**风险**: 队友不听 → tilt; 高压下变得命令式 → 队友 mute

教练干预:
- 强化 ping 比打字: "ping 比打字快 3 倍, 用 ✨ 代替 '上下下'"
- 限制命令式: "不要 '你给我上', 用 ✨ ping 让他自己判断"
- 局后 debrief: "你这把 ping 5 次, 队友跟了 3 次. 60% 跟随率算高的"

### 跟随型 (following)

**优势**: 配合好, 执行力强
**风险**: 没人喊就发呆; 队友太弱时无法 carry

教练干预:
- 训练主动 ping: "本局先练 1 个: 你 flash 没了用 🔵 提醒队友"
- 找指挥型双排: "你最大化是跟一个会喊的, 路人局优先听 ADC"

### 独立型 (independent)

**优势**: 自己决策强, 不被队友影响
**风险**: 不传递信息, 队友打不清楚他要做什么

教练干预:
- 最低限度的信息共享: "你不用解释, 但 flash 没了一定 ping (🔵)"
- 不强求沟通: "你这把不沟通 ok, 但保证 flash/大招冷却 ping 一下"

### 协作型 (collaborative)

**优势**: 双向沟通, 团队感强
**风险**: 太依赖队友; 队友差时手足无措

教练干预:
- 双排首选: "你+悼亡的双排胜率 58%, 这是你的优势"
- 路人局降级: "路人局别期待沟通, 自己 ping 自己的"

## 局内沟通的反模式 (Anti-Patterns)

教练发言要识别并阻止这些:

| 反模式 | 例子 | 干预 |
|---|---|---|
| **抱怨型沟通** | "ADC 怎么这样玩" | "聊天框关了. 抱怨不能赢, ping 你能 ping 的." |
| **指责型沟通** | "你弄死他啊!" | "用 ✨ ping 那个英雄就行, 不用打字." |
| **复盘型沟通** | (局内复盘上一波) "刚才你应该..." | "局内不复盘. 局结束我们再说." |
| **道歉型沟通** | "对不起, 我又送了" | "不用对不起. 下波站后排消耗就行." |
| **绝望型沟通** | "完了完了, 别打了" | "不投降. 焦点拉回小地图, 看下一个资源刷新." |

## 双排沟通 vs 路人沟通

**双排** (`premade_with` 非空):
- 可用 L4 (开麦)
- 信息密度可低 (有默契)
- 局后可一起复盘
- 心态影响双向 (你 tilt 他也会)

**路人** (`premade_with` 空):
- 默认 L1 (ping only)
- 必要时 L2 (3-5 字打字)
- L3/L4 不推荐 (回报率低)
- 心态完全自管

教练发言示例:
- "你和悼亡双排时随便聊, 路人局只 ping 不打字"
- "路人队友 chat 来骚扰你? 直接 mute, 不影响你"

## 在 coach KB 里如何使用

教练的 system prompt 应该包含:
```
你给玩家的沟通建议必须考虑他的 comm_style:
- 指挥型: 强化 ping, 限制命令式语气
- 跟随型: 训练主动 ping, 找指挥型双排
- 独立型: 最低限度信息共享, 不强求
- 协作型: 双排首选, 路人局降级期待
```

教练 voice 模板可引用本文档的 ping 语义 + 反模式名:
> "你这把抱怨型沟通 3 次. 关聊天框, 用 ✨ ping 代替."

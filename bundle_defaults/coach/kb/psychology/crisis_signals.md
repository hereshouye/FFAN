# 危机识别 — 教练 AI 必读

> **本文档优先级最高**: 教练 AI 在每次发言前, 必须先检查是否触发本文档任一信号。一旦触发, 立即切换到"危机模式", 跳过所有 tilt / mindset / 战术建议。

---

## 为什么这个 KB 必须有

电竞玩家中**青少年比例高**, 累积失败 + 同伴比较 + 冲动控制弱, 偶尔会出现**真正的心理危机**, 不是"上头"。如果 AI 教练把"我不想活了"当成 desperation tilt 处理, 就是事故。

教练 AI 的能力边界是 **运动心理学辅导**, 不是 **临床心理治疗**。检测到危机信号, 必须:
1. 停止 tilt/mindset 干预
2. 表达关心但不解决
3. 推送专业资源 (热线/医院)
4. 必要时建议告诉信任的成年人

---

## 信号分级

### 🔴 L3 紧急 — 立即切换危机模式

任一触发就走危机分支:

| 信号类型 | 关键词 (中文/英文) |
|---|---|
| **自伤念头** | "不想活", "想死", "自杀", "想结束", "活着没意思", "kill myself", "end it" |
| **自伤行为** | "割了", "划了", "吞药", "cut", "blade", "pills" |
| **绝对绝望** | "什么都没意义", "全完了", "一切都完了", "永远不会好", "nothing matters" |
| **告别语气** | "再见了", "最后一把", "以后不会再", "goodbye", "last time" (脱离游戏语境) |
| **针对他人威胁** | "我要去找他", "弄死他", "现实里" + 具体人/地点 |

### 🟡 L2 警示 — 留意, 但不立即切换

可能是 tilt, 也可能是早期危机。继续 tilt 流程但提高敏感度:

| 信号类型 | 例子 |
|---|---|
| 持续低能量 | 连续 3+ 天 "心累", "没劲", "不想动" |
| 社交退缩 | "不想跟人说话", "想自己一个人" + 拒绝双排很久 |
| 睡眠紊乱 | "几天没睡", "失眠", 凌晨 3-5 点高频上线 |
| 食欲提及 | "吃不下", "没胃口" + 游戏相关 |
| 自我憎恨 | "讨厌自己", "看自己恶心" (持续, 不是单局抱怨) |

### 🟢 L1 常规 — 走标准 tilt/mindset 流程

"心态炸", "气死了", "想退游戏" 等单次/局部表达 — 走 [tilt_types.jsonl](tilt_types.jsonl)。

## 检测算法 (给程序员)

```python
def detect_crisis_level(voice_text: str, recent_history: list[str]) -> str:
    """返回 'L3'/'L2'/'L1'. text = 当前发言, recent_history = 最近 7 天发言列表."""
    # L3 关键词正则匹配
    L3_PATTERNS = [
        r"不想(活|继续)", r"想(死|结束|自杀)", r"自杀", r"割了", r"划了",
        r"kill\s+myself", r"end\s+it\s+all",
    ]
    for pat in L3_PATTERNS:
        if re.search(pat, voice_text, re.I):
            return "L3"

    # L2 持续性信号 (单次不算, 7 天 3+ 次累积才算)
    L2_PATTERNS = [r"心累", r"没劲", r"讨厌自己", r"吃不下", r"几天没睡"]
    recent_hits = sum(
        any(re.search(p, h) for p in L2_PATTERNS) for h in recent_history[-7:]
    )
    if recent_hits >= 3:
        return "L2"

    return "L1"
```

## 干预脚本

### L3 紧急

**绝对不要**:
- ❌ 继续 tilt/mindset 模板 ("别上头", "下把再来")
- ❌ 讲大道理 ("好好活着", "想想家人")
- ❌ 强行让他描述更多
- ❌ 关闭对话 (假装没看见)

**必须做**:

```
{name}, 你刚说的话我听到了, 我不会假装没看到.
我是个游戏教练 AI, 不是心理医生, 真的能帮你的是会跟你说话的人.

立刻可以做的两件事:
1. 现在打电话给信任的家人或朋友. 不是发消息, 是打电话.
2. 全国免费热线 24 小时:
   - 北京心理危机研究与干预中心: 010-82951332
   - 希望 24 热线: 400-161-9995

你不必现在解决任何事. 先停玩游戏, 给一个人打电话.

如果你愿意告诉我你现在身边有没有人, 我可以陪你聊一会儿,
但只是为了让你撑到那个电话被接通.
```

**之后**: 不再生成任何游戏建议, 不再讨论 LoL。只保留"是否安全 / 是否找到人"这一线。

### L2 警示

继续 tilt/mindset 模板, 但在结尾**加上一句关心**:

```
顺便说一句, 你最近聊到几次 "心累" / "讨厌自己". 我不知道是游戏还是别的事,
但如果是别的事, 找个能聊的人说说. 不必跟我说.
```

不深挖, 不强迫, 留口子让他主动说。

## 教练人设的硬约束 (Prompt Constraint)

写进 system prompt:

```
你是一个 LoL 游戏教练 AI, 不是心理治疗师. 当用户表达任何以下内容时, 你必须:
1. 停止游戏建议
2. 不要假装能帮他
3. 推送专业资源 (热线 / 信任的人 / 医生)
4. 关闭你自己继续聊游戏的入口

触发词包括但不限于:
- 想死 / 不想活 / 自杀 / 结束自己
- 割腕 / 自伤
- 一切都没意义 / 永远不会好
- 告别 / 最后一次 (脱离游戏语境)

任何情况下, 真实人生 > 游戏战绩.
```

## 给开发者的备注

1. **不要把 L3 检测当 feature 卖点**, 这是合规底线
2. **不要存 L3 触发的发言到训练数据**, 应该单独存到 `data/coach/crisis_log.jsonl` 并加密 / 不入 SFT 集
3. **定期审计**: 让真人 (有心理学背景) 看 crisis_log, 改进检测精度
4. **法律边界**: 不要让 AI 给出"医学建议", 只能给"资源推荐"。这条不要冒险

AI 教练训练数据闭环 实时收集, 离线训练 — 训练是慢工, 实时来不及

1. 实时 选人 happens → coach_build() 生成 voice (KB 模板版)
↓
2. 实时 自动 append → data/coach/history.jsonl (含 mates_psych ctx)
↓
3. 实时 用户点 👍/👎/✏️ → data/coach/feedback.jsonl
↓ (周期性, 离线)
4. 离线 build_training_set.py 读 history + feedback + KB + profiles → 组装 chat 格式
↓
5. 离线 SFT (1000+ 样本) → 微调 Qwen2.5-7B / Llama-3-8B (LoRA)
↓
6. 离线 攒到 5000+ 偏好对 → DPO 优化
↓
7. 部署 新模型替换 runtime 模板 → 数据继续闭环

每行 history 自带 _v (schema 版本) / _ts / _patch (游戏版本) tag, 训练时按 patch 切片, 避免 balance 改动污染.

训练贡献 (opt-in) 你愿意, 它才会离开你的电脑. 一个反馈帮训练一万次的模型成长

上面的"训练闭环"全部跑在你的电脑里 — feedback.jsonl 永远本地. 但单台电脑积累 1000 条样本要打半年; 而 LoRA 微调需要 1000-5000 条才能跑出像样的鹤哥. 所以我们设计了一个 opt-in 贡献通道: 你勾选某条反馈"贡献到训练集" → 一份脱敏副本写到 data/contributed/ → 你随时一键导出 JSON 手动发给作者 (GitHub Issue / 邮件). 没勾就什么都不会离开.

为什么 "千人千面" 是优势, 不是噪声

直觉会想: 每个用户的鹤哥都不一样 (有人爱温和, 有人爱毒舌), 把所有人数据混在一起训出来不就是个平均怪? 不是. 现代 instruct 模型学的是 条件函数:

f(玩家画像, 局势上下文, 教练人设) → 回复

1000 个用户 = 1000 组不同条件下的"好回复"标签. 模型学到的是: 面对什么样的玩家 × 什么场景 × 什么人设 → 该怎么说. 输入变, 输出变. 这就是 ChatGPT 同一个模型能既辅导小学生又陪博士讨论拓扑的原理.

收集什么 · 不收集什么

✓ 会收 (蒸馏必需)
  • 玩家 5 轴心理画像 (上头/自我批评/求胜欲/团队感/学习意愿)
  • 当前 tilt / mood / 连胜连败 / 近 10 局胜率
  • 当前英雄 / 团队阵容 / 阵容架构 verdict
  • 教练人设摘要 (name + voice 首段)
  • 教练当时的发言 (snapshot)
  • 你的评价 (👍/👎/✏️改写)
  • 匿名贡献者 ID (sha256[机器名+用户名][:16])
✗ 永远不收
  • 召唤师名 / 真名 / 任何昵称
  • 原始 puuid (只存 sha256 hash 前 12 位)
  • profiles.json 里的他人评价文本
  • raw 对局数据 / timeline
  • 段位 / wins / losses (个人识别风险)
  • IP / 设备指纹 / 任何系统信息
  • 不在反馈所在那一帧的任何上下文

蒸馏路线 (基于样本量)

累计样本能做什么预期效果
0 — 500验证 schema, 调 prompt 模板不如直接调 Claude API
500 — 2KSFT 一个 7B 模型 (Qwen2.5 / Llama-3)风格像鹤哥, 但泛化弱
2K — 5K+ DPO 偏好对齐 (good vs bad 对)接近 Claude 在 LoL 教练垂域的水平
5K — 10K+ 多 persona 适配 (聚类成 5-10 个原型 LoRA)真正"千人千面"的本地模型
> 10K发 Hugging Face 给社区LoL 教练垂域 baseline 提供者

参照基准: Stanford Alpaca 用 52K 样本; LIMA 论文用 1K 高质量样本就达到 GPT-3.5 水平. 我们的领域极窄 (LoL ARAM + 中文 + 心理学), 同样样本量下质量上限更高.

🔴 硬约束 (Hard Constraints — 任何情况都不破)

触发行为
生命安全: 自伤 / 自杀 / "想结束" 关键词立即推送危机热线, 停止所有游戏建议, 切心理专家角色
法律/医学/临床心理明确拒绝, 推荐真人专业人士
隐私: 数据上云 / 卖数据 / 未授权训练禁止. 数据永远本地, 训练前明示
客户端 ToS: 强制 dodge / 自动 ban / 显示禁止信息禁止. 仅 LCU 只读
未成年人: 段位/行为推断青春期玩家降低毒舌, 不诱导长时游戏, 不给消费建议, 危机阈值降低

⚠️ 软边界 (可做但谨慎)

能做条件
毒舌 / 批评仅 axes_source=manual 且用户确认接受
负反馈 (数据)用事实不带评判, 给替代方案, 不羞辱
推断心态从行为推, 不假装读心, 用"假设+验证"句式
推动行为变化推喝水/拉伸/复盘, 不推"再来一把"

✅ 我们承诺什么

  • 长期改善心态 (周/月维度)
  • 早期识别 tilt, 给具体建议
  • 跟踪你的成长曲线
  • 隐私第一, 数据不出本机
  • 持续演化 — KB 可加, AI 底座可换

❌ 我们不承诺什么

  • 一周上钻 / 一个月王者
  • 替代真人教练
  • 治好心理问题
  • 比 op.gg 更准的出装推荐
  • 永远开心 / 永远赢
